# قالب فرزند پاپکورن

چایلد خام قالب پاپکورن؛ بدون تغییر ظاهری یا جایگزینی فایل‌های قالب مادر.

ابتدا قالب `popcorn` را نصب کنید، سپس ZIP چایلد را از «نمایش ← پوسته‌ها ← افزودن ← بارگذاری پوسته» نصب و فعال کنید.

CSS اختصاصی را در `style.css` و کد PHP را پس از کد بارگذاری استایل در `functions.php` اضافه کنید. برای تغییر یک تمپلیت، فقط همان فایل را با مسیر یکسان از قالب مادر به این پوشه کپی کنید. فایل `functions.php` مادر را کپی نکنید.

تنظیمات عمومی پاپکورن حفظ می‌شوند. تنظیمات استاندارد وردپرس وابسته به پوسته، مانند لوگو و جایگاه‌های منو، ممکن است پس از فعال‌کردن چایلد به تخصیص مجدد نیاز داشته باشند.
